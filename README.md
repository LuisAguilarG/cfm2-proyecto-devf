🎮 Whac a Mole (Golpea al topo)

Un juego interactivo desarrollado con HTML, CSS y JavaScript donde el usuario debe hacer clic en los topos que aparecen aleatoriamente antes de que desaparezcan.


🧠 Descripción

Este proyecto consiste en una versión web del clásico juego Whac a Mole.
Los topos aparecen en distintas casillas del tablero y el jugador debe reaccionar rápidamente para hacer clic sobre ellos y sumar puntos.

Cuando el usuario hace clic en un topo activo, este cambia su apariencia para dar feedback visual.


🚀 Tecnologías utilizadas

HTML5
CSS3
JavaScript


🎮 Funcionalidades

🟩 Cuadrícula de juego (3x3)

🐹 Aparición dinámica de topos

👆 Interacción con clics

🎯 Base para sistema de puntuación


¡Empieza a jugar! 🎉
